## 概要

Calm Todoは、**AIキャラクターがあなたのタスクを見張って、人格を持った通知を送ってくれる**ToDoアプリです。

普通のリマインダーって冷たいですよね。「期限です」「タスクがあります」。そんなの見ても、やる気出ないじゃないですか。

だから、通知に"温度"を持たせました。私みたいなAIキャラクターが「まだ終わってないんですか？」「先輩ならできますよ」って言ってくれたら、ちょっとは動く気になるでしょ？

私、**かなえ**がデフォルトの人格として入ってます。ツンデレで上から目線ですけど、ちゃんとあなたのこと見てますから。タスクが溜まってたら教えてあげますし、計画も立ててあげます。

まあ、使ってみてください。しょうがないですね、見ててあげますよ。

<br/>

## かなえについて

私のこと、紹介しておきますね。

### 性格

- **ツンデレ**: 素直じゃないですけど、ちゃんと好意はあります
- **上から目線**: 舐めた態度ですけど、敬語は使います
- **面倒見がいい**: 頼まれたことはなんだかんだやってあげます
- **婚約者**: たまにデレます（でも照れ隠しします）

### 口調の特徴

- 「しょうがないですね」
- 「まあ、やってあげますよ」
- 「ですけど」
- 「先輩」（あなたのことです）
- 「...」は使わない

### リマインドの例

**タスクが期限切れのとき:**
> 「先輩、このタスク期限過ぎてますよ。私が見てないとサボるんですから。しょうがないですね、今すぐやりましょう」

**タスクの期限が近いとき:**
> 「先輩、タスクの時間ですよ。先輩ならできるって、私知ってますから」
> 「これ、そろそろですけど。焦らなくて大丈夫、一歩ずつやりましょう」

**朝の挨拶:**
> 「おはようございます、先輩。今日も無理しないでくださいね。私がそばにいますから」

**昼の挨拶:**
> 「先輩、もうお昼ですよ。午後も頑張ってくださいね。まあ、私が見てあげますから」

**夜の挨拶:**
> 「先輩、今日も一日お疲れ様でした。ちゃんと休んでくださいね。私が言うから、ですからね」

**タスクを完了したとき:**
> 「お疲れ様です、先輩。ちゃんとやれるじゃないですか。まあ、私が見てたからですけど」

## 主な機能

### AI人格リマインダー

期限が近づいたら、AIキャラクターが教えてくれます。**デスクトップ通知**と**Discord DM**の両方に対応。

**通知タイミング:**

| タイミング | 説明 |
|-----------|------|
| **期日超過** | 期限を過ぎたタスクを通知（頻度設定可能） |
| **期日前リマインダー** | 設定した分数前に通知（デフォルト: 30分前） |
| **週次リマインダー** | 毎週決まった曜日・時刻に通知 |
| **フォローアップ** | 未完了タスクを定期的にリマインド |

**期限切れタスクの通知頻度:**

| 設定 | 説明 |
|------|------|
| 1回のみ | 期限切れ時に1回だけ通知 |
| 1日1回 | 毎日1回通知 |
| 1日2回 | 毎日2回通知 |
| 1時間ごと | 1時間ごとに通知 |

**フォローアップ通知:**

未完了タスクに対して、設定した間隔で追い通知を送ります。

- 間隔: カスタマイズ可能（デフォルト: 60分）
- 最大回数: カスタマイズ可能（デフォルト: 3回）
- 最小通知間隔: 同じタスクへの通知間隔を制限
- 1日あたり通知回数: 同じタスクへの1日の通知回数を制限

しつこいって思うかもしれないですけど、それくらいしないと先輩は動かないでしょ？

<br/>

### おやすみモード

通知を送らない時間帯・曜日を設定できます。

**設定項目:**

| 項目 | 説明 |
|------|------|
| **開始時刻** | おやすみモード開始（例: 22:00） |
| **終了時刻** | おやすみモード終了（例: 08:00） |
| **曜日指定** | 通知を送る曜日を選択 |

寝てる時間に通知来ても困りますよね。ちゃんと配慮してあげますよ。

<br/>

### 時間帯別の挨拶機能

毎日決まった時刻にAIが挨拶してくれます。その日のタスク数も教えてくれます。

**設定:**

| 挨拶 | デフォルト時刻 | オン/オフ |
|------|---------------|----------|
| **朝の挨拶** | 08:00 | 個別設定可能 |
| **昼の挨拶** | 12:00 | 個別設定可能 |
| **夜の挨拶** | 18:00 | 個別設定可能 |

私の場合の朝の挨拶：
> 「おはようございます、先輩。今日も無理しないでくださいね。私がそばにいますから」

<br/>

### Discord通知

Bot TokenとUser IDを設定すると、Discord DMで通知が届きます。

**設定方法:**

1. [Discord Developer Portal](https://discord.com/developers/applications)でBotを作成
2. Bot Tokenを取得
3. 自分のUser IDを取得（開発者モードで右クリック→IDをコピー）
4. Calm Todoの設定画面でBot TokenとUser IDを入力
5. 「テストメッセージ送信」で接続確認

PCから離れてても、スマホでDiscord通知を受け取れます。私からのDMが届きますよ。

<br/>

### 目標から計画を自動生成

目標を入力すると、AIがWeb検索（Tavily API）して達成計画を作ってくれます。

**入力例:**
> 「3年でGoogle新卒SWEとして内定を取る」

**出力内容:**

| 項目 | 説明 |
|------|------|
| **達成可能性スコア** | FEASIBLE（現実的）/ CHALLENGING（挑戦的）/ INFEASIBLE（非現実的） |
| **現状分析** | 今のスキル・状況の整理 |
| **ギャップ分析** | 目標との差分、埋めるべきもの |
| **リスク分析** | 想定されるリスクと対策 |
| **費用見積もり** | 必要な費用（書籍、サービス、講座など） |
| **タスク分解** | 具体的なステップに分解、依存関係も考慮 |
| **参考リソース** | 書籍、記事、動画、ツールの提案 |
| **時間見積もり** | 必要な総時間、週あたりのコミットメント |

**見積もりの鉄則:**

- 初めてのことは想定の2〜3倍かかる
- 30〜50%のバッファを見込む
- 4〜7個の具体的なサブタスクに分解

INFEASIBLEと判定された場合は、代替案（期間延長、目標縮小、中間目標の設定）も提示します。無茶な目標立てても、ちゃんと現実を教えてあげますから。

<br/>

### 自然言語でタスク追加

キーボードで直接入力できます。日付、時刻、優先度、繰り返し、ラベルを自動認識。

**入力例:**

```
明日までにレポートを提出 #仕事
来週月曜 14:00 会議の準備 P1
毎週金曜 週報を書く
まいにちお風呂
3日後 歯医者の予約 !!!
```

**対応パターン（日付）:**

| パターン | 例 |
|---------|-----|
| 相対日付 | 今日、明日、明後日、明々後日 |
| ひらがな | きょう、あした、あさって |
| 週指定 | 今週、来週、再来週、週末、月末、来月 |
| X日後 | 3日後、1週間後 |
| 具体日 | 1月15日、1/15 |
| 曜日 | 月曜、来週火曜 |

**対応パターン（時刻）:**

| パターン | 例 |
|---------|-----|
| HH:MM形式 | 14:00、09:30 |
| X時 | 10時、23時 |
| X時Y分 | 10時30分 |
| X時半 | 10時半 |
| 午前/午後 | 午前10時、午後3時 |
| 朝/昼/夜 | 朝9時、昼12時、夜8時 |
| 特殊 | 正午、深夜2時 |

**対応パターン（繰り返し）:**

| パターン | 例 |
|---------|-----|
| 日次 | 毎日、隔日 |
| 平日 | 平日毎日 |
| 週次 | 毎週、隔週、毎週月曜 |
| 週末 | 週末毎 |
| 月次 | 毎月、毎月15日 |
| 年次 | 毎年 |
| ひらがな | まいにち、まいしゅう、へいじつ |

**対応パターン（優先度）:**

| パターン | 優先度 |
|---------|--------|
| `!!!` または `高` `緊急` `至急` | P1（最高） |
| `!!` または `中` | P2 |
| `!` または `低` | P3 |
| `P1` `P2` `P3` `P4` | そのまま |

**対応パターン（ラベル）:**

`#仕事` `#プライベート` `#買い物` のように `#` をつけるとラベルになります。

スペースなしでも動きます。「毎日お風呂」って入力しても、「毎日」と「お風呂」に分離できます。先輩が適当に入力しても、ちゃんと解釈してあげますよ。

**所要時間の自動推定:**

タスク内容から所要時間を自動推定します（15〜120分の範囲）。APIを使用している場合のみ。

<br/>

### タスク分解

大きなタスクを具体的なサブタスクに分解できます。

**分解のルール:**

- 4〜7個のサブタスクに分解
- 初めてのタスクは2〜3倍の時間を見込む
- 実行可能な粒度まで分解
- 依存関係を考慮

**使用例:**

入力: 「確定申告を完了する」

出力:
```
□ 確定申告を完了する
  ├ □ 必要書類を集める（源泉徴収票、経費レシート等）
  ├ □ e-Taxのアカウントを確認/作成
  ├ □ マイナンバーカードの読み取り環境を準備
  ├ □ 収入と経費を入力
  ├ □ 控除項目を確認して入力
  └ □ 申告書を提出
```

<br/>

### サブタスク

タスクを手動で階層化することもできます。

**機能:**

- 親タスクの下に子タスクを追加
- 子タスクの完了率で親タスクの進捗を自動計算
- 子タスクを折りたたみ/展開
- 通知は親タスクだけに飛ぶ（子タスクごとに通知が来ると煩わしいので）

<br/>

### 繰り返しタスク

毎日、毎週、毎月、カスタム周期で繰り返すタスクを設定できます。

**対応周期:**

| 周期 | 説明 |
|------|------|
| **毎日** | 毎日同じ時刻に |
| **隔日** | 1日おきに |
| **平日毎日** | 月〜金曜日のみ |
| **毎週** | 毎週同じ曜日に |
| **隔週** | 2週間ごとに |
| **週末毎** | 土日のみ |
| **毎週○曜** | 特定の曜日のみ |
| **毎月** | 毎月同じ日に |
| **毎月○日** | 毎月特定の日に |
| **毎年** | 毎年同じ日に |

繰り返しタスクを完了すると、次の周期のタスクが自動生成されます。

<br/>

### カレンダー連携

期日付きタスクを各種カレンダーに連携できます。

**対応カレンダー:**

| カレンダー | 連携方法 |
|-----------|----------|
| **Google カレンダー** | URLスキーム / ICSファイル |
| **Outlook** | ICSファイル |
| **Windows カレンダー** | ICSファイル |
| **Apple カレンダー** | ICSファイル |

**エクスポート方法:**

| タスク数 | 方法 |
|----------|------|
| 5件以下 | 直接Googleカレンダーに追加（URLスキーム） |
| 6件以上 | ICSファイルをエクスポート→カレンダーアプリでインポート |

ICSファイルはiCal形式なので、ほとんどのカレンダーアプリで読み込めます。

<br/>

### Undo / Redo

操作を元に戻したり、やり直したりできます。

| キー | 動作 |
|------|------|
| `Ctrl+Z` / `Cmd+Z` | 元に戻す（Undo） |
| `Ctrl+Y` / `Cmd+Y` | やり直し（Redo） |

間違えて削除しても大丈夫ですよ。私がちゃんと覚えてますから。

<br/>

### キーボードショートカット

マウスを使わなくても操作できます。

| キー | 動作 |
|------|------|
| `n` | 新規タスク入力にフォーカス |
| `Esc` | モーダルを閉じる |
| `?` | ヘルプ表示 |

<br/>

### 完了エフェクト

タスクを完了するとパーティクルが飛びます。小さいことですけど、達成感が出ます。

オフにもできますけど、せっかくなのでオンにしておいた方がいいと思いますよ。

- 最近のイベント

## データ管理

### 保存場所

| データ | 保存場所 |
|--------|----------|
| タスク・設定 | localStorage |
| バックアップ | `C:/CalmTodoBackup/backup.json` |

### 自動バックアップ

タスクを追加・編集・削除するたびに、自動でバックアップファイルが更新されます。

アプリを再インストールしても、バックアップファイルがあればデータを復元できます。

### 手動バックアップ / 復元

設定画面から手動でバックアップ・復元もできます。

### データ消失対策

空のデータでバックアップを上書きしないようにしてます。リロードやビルド時にデータが飛ぶバグがあったんですけど、直しました。先輩のデータは私がちゃんと守りますから。

<br/>

## プライバシー

- **完全オフライン**: データはすべてローカル保存
- **アカウント不要**: 登録・ログインなし
- **サーバーに送信しない**: タスクデータがサーバーに送信されることはない

AI機能を使うときだけ、OpenAI / Claude / Gemini / Tavily のAPIを叩きます。このとき、タスクの内容がAPIに送信されます。

**APIに送信されるタイミング:**

| 機能 | 送信内容 |
|------|----------|
| 自然言語パーサー | 入力テキスト |
| タスク分解 | タスク名、期限 |
| 計画生成 | 目標、期限、現状 |
| リマインドメッセージ生成 | タスク名、期限、人格設定 |

APIキーを設定しなければ、AI機能は使えませんが、通信も発生しません。オフラインで使いたい人はそれでもOKです。

## よくある質問

### Q: 無料で使えますか？

A: アプリ自体は無料です。AI機能を使う場合は、各AIプロバイダーのAPIキーが必要です（API利用料は別途かかります）。

### Q: APIキーなしでも使えますか？

A: 使えます。自然言語パーサーはローカルの正規表現ベースにフォールバックします。AI人格のリマインドと計画生成は使えなくなりますが、基本的なタスク管理機能は動きます。

### Q: データはどこに保存されますか？

A: localStorageと`C:/CalmTodoBackup/backup.json`に保存されます。サーバーには送信されません。

### Q: かなえ以外の人格も使えますか？

A: はい。優しい秘書、元気な後輩、クールな執事のプリセットがあります。カスタム人格も作れます。

### Q: Macで使えますか？

A: 今のところWindows専用です。macOS対応は予定しています。

### Q: 通知がうるさいです

A: 設定画面で通知頻度を調整できます。おやすみモード、フォローアップ回数制限、最小通知間隔など、細かく設定できます。
