# 全If-Thenルール ＆ iOS向け即時記録・ツイートツール要件定義書

日常のあらゆるアクション（運動・仕事・英語・お絵描き・To-Do策定）を「If-Thenルール」で自動化し、さらに**実行した直後にiPhone / iPadからワンタップ（1秒）で自サイトへの記録とX（旧Twitter）へのツイートを完了させるツール**の統合設計書です。

## 第2部：iOS向け「If-Then 即時記録 ＆ ツイートツール」システム要件定義書

### 1. アーキテクチャ方針（App Store不要・起動0.5秒構成）

iPhone / iPad で「アプリを探して起動し、文字を打って投稿する」という摩擦を完全に消すため、以下のハイブリッド構成を採用する。

1. **フロントエンド（PWA / Next.js or Astro等）：**
   * 自サイト内の専用ルート（例：`https://your-site.com/habit`）をPWA化し、ホーム画面に追加。
2. **iOSネイティブ連携（Apple ショートカット ＋ ウィジェット ＋ URLスキーム）：**
   * ロック画面・ホーム画面に配置した**iOSショートカットウィジェット**から、バックグラウンドで自サイトAPI（`POST /api/habit/log`）へ実績を送信。
   * レスポンスで返却された「自動生成ツイート文面」を受け取り、iOSのURLスキーム `x://post?message=...`（または `twitter://post?message=...`）を自動起動して**Xの投稿画面が文面入力済みの状態で即座に開く**仕組みにする。

---

### 2. 機能要件一覧

#### ① ワンタップ即時実行ウィジェット（iOSショートカット連携）
iPhoneのホーム画面・ロック画面・コントロールセンターから**1タップ**で発火するアクション群。

* **アクションA：【日中スキマ記録＋即ツイート】**
  * ボタン例：`[トイレSQ30＋英語]` `[ジャンプSQ20]` `[スクショ資料保存]` `[仕事25分初動]`
  * **挙動：** タップ $\rightarrow$ 自サイトDBの該当カウントを `+1` $\rightarrow$ Xアプリが自動起動し、以下のような定型文が入力された状態で開く（ユーザーは右上の「ポスト」を押すだけ）。
  * **生成文面例：**
    > トイレ後のワイドスクワット30回＋英語アプリ1レッスン完了！
    > 本日の累計SQ：60回 / 連続15日目🔥
    > #IfThen習慣 #今日の積み上げ
* **アクションB：【夜の全完了総括＋翌日To-Do登録】**
  * 夜の筋トレ・バイク・風呂・お絵描き完了後にタップして開く専用画面。
  * **入力項目（すべてタップ中心）：**
    * 完了チェック：`[✓] 再生前筋トレ3set` `[✓] バイク(1話/2話)` `[✓] 英語シャドーイング` `[✓] iPadクロッキー`
    * 画像添付（任意）：iPadで描いたクロッキー画像を1枚選択（クリップボードへ自動コピー＋自サイトギャラリーへ保存）。
    * **明日の最重要To-Do入力欄（最大3行）：** テキストボックス×3枠。
  * **挙動：** 「記録してXへ投稿」タップ $\rightarrow$ 自サイトDB保存（今日のログ確定＋明日のTo-Do保存） $\rightarrow$ 総括ツイート文面を持ってXアプリ起動。

#### ② 自サイト公開用ダッシュボード（モチベーション可視化）
自サイト訪問者および自分自身が見て達成感を得るための公開コンポーネント。

* **翌日To-Doウィジェット（オーナー専用表示）：**
  * 朝PCで自サイトを開いた際、前夜に設定した「今日の最重要To-Do 3つ」が画面最上部に大きく表示され、完了したらワンクリックで打ち消し線を引ける。
* **GitHub風アクティビティヒートマップ（草）：**
  * 過去365日のIf-Then達成スコアに応じてマス目の色の濃さが変化。
* **累計スタッツ＆ストリーク表示：**
  * `連続達成日数（🔥 Day XX）`、`累計スクワット回数`、`累計バイク走行時間`、`クロッキー枚数`、`英語レッスン数`。
* **クロッキー＆ログタイムライン：**
  * アップロードしたiPadお絵描き画像と一言メモの時系列ギャラリー。

### 3. API ＆ データ設計（バックエンド仕様）

#### APIエンドポイント仕様

1. **`POST /api/habit/quick`（iOSショートカットからの即時加算用）**
   * **認証：** リクエストヘッダに個人用APIトークン（`Authorization: Bearer <SECRET_TOKEN>`）を付与（iOSショートカット内に保存）。
   * **リクエストボディ（JSON）：**
     ```json
     {
       "action_type": "toilet_sq_en",
       "value": 1
     }
     ```
   * **レスポンス（JSON）：**
     ```json
     {
       "status": "ok",
       "streak_days": 15,
       "today_summary": { "squat": 60, "english": 2 },
       "tweet_text": "トイレ後のワイドSQ30回＋英語1レッスン完了！\n本日累計SQ：60回（連続15日目🔥）\n#IfThen習慣"
     }
     ```

2. **`POST /api/habit/daily-close`（夜の総括記録 ＆ 翌日To-Do登録用）**
   * **リクエストボディ（JSON / Multipart）：**
     * 完了フラグ群（筋トレ、バイク分数、お絵描き、仕事初動）
     * `image_file`（クロッキー画像・任意）
     * `next_todos`: `["タスク1", "タスク2", "タスク3"]`（最大3件）
   * **処理：**
     * 当日ログを確定保存（日付境界は**朝4:00切り替え**ロジックを適用）。
     * `todos` テーブルに翌日日付のタスクを最大3件登録。
     * X投稿用の総括テキストを生成して返却。

#### データベーステーブル構成案

* **`habit_logs`（日次実績）**
  * `id`, `target_date` (DATE / UNIQUE), `squat_count` (INT), `pushup_sets` (INT), `abs_sets` (INT), `bike_minutes` (INT), `english_count` (INT), `drawing_done` (BOOL), `screenshot_count` (INT), `work_focus_done` (BOOL), `drawing_image_url` (TEXT), `updated_at`
* **`daily_todos`（前夜決める翌日の3タスク）**
  * `id`, `target_date` (DATE), `priority` (1〜3), `title` (TEXT), `is_completed` (BOOL), `created_at`

### 4. iOSショートカット構築フロー（実装イメージ）

iPhone / iPad 側で作成するショートカットのアクション配列（わずか4ステップ）：

1. **【URLの内容を取得】** `POST https://your-site.com/api/habit/quick`（HeaderにBearerトークン、JSONに実行アクション名を指定）
2. **【辞書値を取得】** レスポンスJSONから `tweet_text` を抽出
3. **【URLエンコード】** `tweet_text` をURLエンコード
4. **【URLを開く】** `x://post?message=[エンコード済みテキスト]`（Xアプリがインストールされていない環境向けに `https://twitter.com/intent/tweet?text=...` へフォールバック可能）

> **運用上のメリット：** このショートカットをiPhoneの「ロック画面ウィジェット」「ホーム画面アイコン」「背面タップ（ダブルタップ）」、およびiPadの「コントロールセンター」に配置しておくことで、**筋トレ直後やトイレから出た瞬間に、ロック解除すらほぼ意識せず1タップで自サイト更新＋X投稿画面起動まで完結**します。
