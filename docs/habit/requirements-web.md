# 全習慣統合 If-Thenルール ＆ サイト記録・X連携機能要件書

意志力に頼らず、**「筋トレ・有酸素運動・仕事効率化・英語学習・お絵描き」**の全習慣を自動化し、さらにその成果を**「自分のサイトへのログ記録 ＆ X（旧Twitter）への発信」**まで一気通貫で完了させるための設計書です。

---

## 第1部：全習慣統合 If-Thenルール（記録・ツイート組み込み版）

### 1. 記録・ツイート専用の If-Then ルール（新規追加）

毎日の努力を可視化し、「継続ストリーク（連続記録）」と「外部への発信」によって脳の報酬系を刺激するルールです。

| トリガー（If：もし〇〇したら） | アクション（Then：△△する） | 狙い・効果 |
| :--- | :--- | :--- |
| **風呂から上がり、iPadのお絵描き（1クロッキー）を描き終えたら** | その流れで**自分のサイトの「本日の記録画面」を開き、完了した項目をタップして保存**する（所要時間10秒） | 1日の全タスク完了の「締めくくりの儀式」として固定化し、記録忘れをゼロにする |
| **サイトに記録を保存したら（完了画面が出たら）** | そのまま表示される**「X（Twitter）で成果をポストする」ボタンを1タップ**して投稿する（＋今日描いたクロッキー画像があれば添付） | 「人に見られている・積み上がっている」という適度な強制力と承認報酬で、翌日のモチベーションを自動生成する |
| **日中のスキマ筋トレ（トイレSQ・レンジ待ち等）や英語アプリを1回やったら** | スマホのホーム画面に置いた**サイトのクイック記録ページ（PWA）で「＋1」ボタンを即タップ**する | 細かい積み上げをリアルタイムで数値化し、ゲーム感覚で総量を稼ぐ |

---

### 2. 1日の完全連結フロー（朝〜就寝まで）

1. **【朝】** 起床して水を飲んだら $\rightarrow$ **プランク90秒 ＋ 腕立て限界1セット**
2. **【仕事】** PCの前に座ったら $\rightarrow$ SNSを見ずに**最重要タスクを25分着手**（90分ごとに**ジャンプSQ20回**）
3. **【スキマ】** トイレに座ったら $\rightarrow$ **英語アプリ1分** $\rightarrow$ ズボンを上げたら**ワイドSQ30回＋空気椅子30秒**
4. **【インプット】** 漫画・アニメを見て「いいな！」と思ったら $\rightarrow$ **即スクショを撮り「お絵描き資料」へ保存**
5. **【夜・運動】** アニメを見ようと思ったら $\rightarrow$ 再生前に**筋トレ3種目×3セット（10分）** $\rightarrow$ エアロバイクで**アニメ1〜2話（OP・ED全力立ち漕ぎ＋英語シャドーイング）** $\rightarrow$ **風呂直行**
6. **【夜・創作】** 風呂上がりで髪を乾かしたら $\rightarrow$ iPadで**1日1クロッキー（3〜5分）**（資料スクショ模写 or 30秒ドローイング）
7. **【夜・記録＆発信】** お絵描きを終えたら $\rightarrow$ **自サイトに今日の成果を記録 ＆ Xへワンタップ投稿**して就寝

## 第2部：自サイト実装用「If-Then 成果記録 ＆ X連携機能」機能要件書

自サイトに組み込む個人用トラッカー（Webアプリ / PWA対応）の要件定義です。**「いかに1タップ・数秒でストレスなく記録とツイートが完了するか（摩擦ゼロのUI）」**を最優先に設計します。

### 1. システム概要・目的
* **目的：** 日々の筋トレ総量・エアロバイク時間・学習・お絵描き等のIf-Then達成状況を自サイト（ポートフォリオ／個人ブログ等）に蓄積・公開し、X（旧Twitter）への投稿をワンクリックで完結させる。
* **非機能要件（最重要）：**
  * **高速起動・PWA対応：** スマホ・iPadのホーム画面からアプリのように即座に起動できること。
  * **摩擦ゼロUI：** 数値のキーボード入力を極力減らし、プリセットボタンのタップだけで記録が完了すること。

---

### 2. 画面・機能要件一覧

#### ① クイック記録ダッシュボード（管理・入力画面）
ログイン済み（オーナー専用）状態でアクセスできる記録用インターフェース。

* **ワンタップ・カウンター機能（リアルタイム加算用）：**
  * 日中のスキマ運動を即座に記録する「＋1」ボタン群。
  * 項目例：
    * `スクワット (+30回)` / `ジャンプSQ (+20回)`
    * `腕立て伏せ (+1セット)` / `腹筋ローラー (+1セット)`
    * `プランク (+90秒)`
    * `英語アプリ (+1レッスン)`
* **メインルーティン・チェックリスト（夜のまとめ入力用）：**
  * トグルスイッチまたはチェックボックスでON/OFF切り替え。
  * 項目例：
    * `[✓] 再生前サーキット筋トレ完了`
    * `[✓] エアロバイク完走`（アニメ話数選択：`1話(24分)` / `2話(48分)` / `カスタム分数`）
    * `[✓] 英語シャドーイング実施`
    * `[✓] iPad 1クロッキー完了`
    * `[✓] 仕事 最重要タスク25分初動クリア`
* **画像アップロード機能（任意）：**
  * iPadで描いたクロッキーや、筋トレ・バイクの走行リザルト画像を1枚添付可能（X投稿時のメディア添付およびサイト上のギャラリー表示用）。
* **一言メモ欄（任意）：**
  * 140字以内の短いコメント入力欄（例：「ブルガリアンSQがキツかった」「アニメの構図模写が上手くいった」）。

#### ② 自動集計・ストリーク（継続日数）ロジック
* **日付境界の設定：** 深夜帯（0:00〜3:59）の運動・お絵描きを前日分として扱えるよう、**「日付変更ライン（例：朝4:00切り替え）」**を設定可能にする。
* **ストリーク計算：** 1つ以上のメインタスクが記録された日を「達成日」とし、現在の連続達成日数（例：`🔥 14日連続達成中`）と累計総量（累計スクワット回数、累計バイク時間など）を自動計算する。

#### ③ X（旧Twitter）連携・自動テキスト生成機能
記録保存と同時に、Xへ投稿するためのテキストを自動整形して出力する機能。

* **投稿方式（以下のいずれか、または併用）：**
  1. **Web Intent方式（実装コスト最小・推奨）：** 保存完了モーダルに「Xでポストする」ボタンを配置し、`https://twitter.com/intent/tweet?text=...` を開く（画像がある場合はクリップボードへ自動コピー、またはダウンロード促し）。
  2. **X API v2 連携方式（完全自動化）：** サイトの保存ボタンを押した瞬間に、バックエンドからX API経由でテキスト＋画像を自動ポストする。
* **自動生成ツイートテンプレート例：**
  ```text
  【Day 15 継続中🔥】今日のIf-Then成果
  💪 筋トレ：腕立て3set / スクワット90回 / 腹筋2set
  🚴 バイク：アニメ2話分（48分・OP/ED全力HIIT）
  🇬🇧 英語：アプリ2レッスン＋シャドーイング
  🎨 お絵描き：1クロッキー完了

  累計SQ：1,350回突破！
  #今日の積み上げ #IfThen習慣 #筋トレ #iPadお絵描き
  ```

#### ④ 公開用アクティビティログ（サイト訪問者向け表示）
自分のサイト（トップページや専用ページ `/logs` など）に公開表示するウィジェット。

* **GitHub風の草（ヒートマップカレンダー）：** 過去1年間の活動量を色の濃淡で可視化。
* **累計スタッツカード：** 「累計スクワット回数」「累計エアロバイク時間」「連続達成日数」「クロッキー枚数」をリアルタイム表示。
* **タイムライン表示：** 日々の達成項目・一言メモ・投稿したクロッキー画像を時系列で表示。

### 3. データモデル設計案（DBテーブル構成）

実装時にそのまま使えるシンプルなテーブル構造案です（SQLite / PostgreSQL / Supabase / Firebase 等に対応）。

#### `daily_logs` テーブル（日次サマリー）
| カラム名 | データ型 | 説明 |
| :--- | :--- | :--- |
| `id` | UUID / INT | 主キー |
| `target_date` | DATE | 対象日（朝4時切り替えロジック適用後の日付・UNIQUE） |
| `squat_count` | INT | その日の合計スクワット回数（デフォルト: 0） |
| `pushup_sets` | INT | 腕立て伏せセット数 |
| `abs_sets` | INT | 腹筋・プランクセット数 |
| `bike_minutes` | INT | エアロバイク漕いだ分数（24分単位など） |
| `english_done` | BOOLEAN | 英語学習（アプリ・シャドーイング）達成フラグ |
| `drawing_done` | BOOLEAN | iPadお絵描き達成フラグ |
| `work_focus_done` | BOOLEAN | 仕事25分初動ルール達成フラグ |
| `image_url` | TEXT | アップロードしたクロッキー等の画像URL（NULL可） |
| `memo` | TEXT | 一言コメント（NULL可） |
| `tweeted` | BOOLEAN | X投稿済みフラグ |
| `created_at` | TIMESTAMP | 作成日時 |
| `updated_at` | TIMESTAMP | 更新日時 |

---

### 4. 開発ステップ（MVP：最小構成からの進め方）

1. **Phase 1（最短1日でリリース）：**
   * `daily_logs` テーブルの作成と、スマホから1タップで数値を加算・保存できる管理画面の実装。
   * 保存後に `X Web Intent` で定型文が入力されたツイート画面が開く機能。
2. **Phase 2（モチベーション可視化）：**
   * 自サイトの公開ページに「累計カウンター」と「GitHub風ヒートマップ（草）」を表示。
3. **Phase 3（完全自動化）：**
   * X API連携によるワンクリック自動投稿（画像添付含む）と、iPadからの画像直接アップロードUIの最適化。
